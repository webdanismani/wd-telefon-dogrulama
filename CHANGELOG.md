# Değişiklik günlüğü / Changelog

## [1.0.0] - 2026-11-23

### Eklendi / Added

- Kayıt formunda NetGSM SMS API v3 ile telefon doğrulaması
  / Phone verification on the registration form via NetGSM SMS API v3
- Sosyal hesapla kayıtta da doğrulama (ayarlanabilir)
  / Verification for connected-account registration (configurable)
- Bir numara ile tek hesap; üye silinince numara serbest kalır
  / One account per number; the number is released when the member is deleted
- Numara, IP ve günlük toplam SMS sınırları, yeniden gönderme bekleme süresi
  / Per-number, per-IP and daily SMS limits, resend cooldown
- Yönetim sayfası: test SMS'i, doğrulanmış numaralar, gönderim kayıtları
  / Admin page: test SMS, verified numbers, send log
- Sandbox ve kurumsal OTP hesabı desteği
  / Sandbox and enterprise OTP account support
- XenForo 2.2 ve 2.3 uyumluluğu / XenForo 2.2 and 2.3 compatibility
